# Design Skills

Browse and save [DESIGN.md](https://getdesign.md) files from [VoltAgent's awesome-design-md](https://github.com/VoltAgent/awesome-design-md) collection directly into your project.

Drop a DESIGN.md into your project root, tell your AI coding agent to use it, and get UI that matches the design system of sites like Linear, Stripe, Notion, Apple, Figma, and more.

## Features

- Browse 60+ DESIGN.md files grouped by 9 categories (AI platforms, Developer Tools, Fintech, Automotive, etc.)
- Filter by category with the dropdown
- Full DESIGN.md preview rendered inline in the detail pane (toggle with `Cmd+D`)
- **Save to Folder…** — pick any directory and filename before writing
- **Save to Default Folder** — one-shot save to the configured default folder as `DESIGN.md`
- Copy the raw GitHub URL, or open the file on getdesign.md / GitHub

## Preferences

- **Default Save Directory** — where one-shot saves land (defaults to `~/Downloads`)
- **GitHub Personal Access Token** — optional; raises GitHub API limit from 60 to 5,000 requests/hour

## Commands

### Search Design Skills

Live browse with category filter, inline DESIGN.md preview, and quick-save actions.
